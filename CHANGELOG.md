# Changelog

## 0.1.0 — 2026-09-15

- First stable release of the composable React split-flap components, Unicode decks, custom looks, CSS/Canvas motion and optional mechanical sound.
- Verified Chromium, Firefox and WebKit behavior, visual baselines, npm/pnpm package exports and React 19.0.0 compatibility.
- Documentation now lives at https://cuvii.dev/flapkit/ with self-hosted fonts, subpath-safe assets and automatic package version display.
- Added reproducible product video source with native motion, colored characters and synchronized native sound.

See README for rendering, styling and compatibility limits.

## 0.1.0-beta.0 — 2026-09-15

- Composable React split-flap boards, grids, rows, groups and single/wide cassettes.
- Unicode decks and editable Face, Glyph and Retainer parts using ordinary CSS.
- Separate CSS cascade and Canvas cascade/riffle entry points; optional mechanical sound.
- Stable public package exports for development and production consumers.
- Mobile documentation improvements, reliable chapter navigation and deck autoplay.

This is a prerelease. See README for rendering, styling and compatibility limits.
